GeorefAuto

Plugin QGIS para georreferenciamento automático de imagens aéreas históricas usando visão computacional

⎇ dev-alvarez Python 3.10+ QGIS 3.x OpenCV 4.x RootSIFT + FLANN + RANSAC Strategy Pattern 13-Step Pipeline

Propósito e Valor Histórico

O GeorefAuto é um plugin QGIS que automatiza o georreferenciamento de fotografias aéreas analógicas digitalizadas — imagens produzidas entre as décadas de 1940 e 1990 por câmeras métricas instaladas em aeronaves. Esses arquivos fotogramétricos constituem o único registro visual de regiões antes da era do sensoriamento remoto digital, documentando paisagens, ocupações e transformações urbanas e rurais que não existem mais.

O processo tradicional de georreferenciamento exige que técnicos identifiquem manualmente pontos de controle terrestres (GCPs) em cada fotografia, tarefa que pode levar horas por imagem e é impraticável para acervos com dezenas de milhares de fotogramas. O GeorefAuto resolve esse problema ao comparar automaticamente a fotografia digitalizada com uma camada de referência geográfica moderna (ex.: imagem de satélite, ortofoto) usando algoritmos de visão computacional.

Detector Principal
RootSIFT
SIFT com normalização L1 + raiz quadrada — invariante a escala, rotação e iluminação
Matcher
FLANN KNN
Fast Library for Approximate Nearest Neighbors com Lowe's Ratio Test 0.75
Estimador
RANSAC
Homografia 3×3 robusta com limiar de reprojeção 5.0 px e confiança 0.995
Saída
GeoTIFF
~1 m/pixel, JPEG compressão, overviews 2×/4×/8×/16×, CRS herdado da referência
Impacto prático: Um acervo de 500 imagens que levaria meses de trabalho manual pode ser processado em lote em horas, com cada imagem resultando em um GeoTIFF pronto para uso em SIG, análise de mudança de uso do solo, estudos de cheias históricas e planejamento urbano.

GeoreferencingConfig — Centro de Controle do Pipeline

Todo parâmetro operacional do pipeline é centralizado em um único dataclass(frozen=True), garantindo imutabilidade em tempo de execução e facilitando testes parametrizados.

@dataclass(frozen=True)
class GeoreferencingConfig:
    # Renderização da referência
    render_width_px: int   = 2000       # largura do raster de referência em pixels

    # RANSAC
    ransac_reproj_thresh_px: float = 5.0  # erro máximo em px para ser inlier
    ransac_confidence: float = 0.995      # probabilidade de resultado sem outliers

    # Reamostragem de saída
    warp_interpolation: int = 3           # cv2.INTER_CUBIC
    target_resolution: float = 1.0       # metros/pixel no GeoTIFF final
    resampling: str = "cubic"
    clamp_upsampling: bool = False        # evita upsampling excessivo

    # Qualidade mínima
    min_features: int = 8                 # mínimo de inliers/keypoints aceitáveis
    min_inlier_ratio: float = 0.25        # mínimo de 25% de inliers sobre matches

    # Validação de polígono
    max_polygon_area_km2: float = 3450.0  # bloqueia execução acima deste limite
    warn_polygon_area_km2: float = 1500.0 # aviso de aviso (área grande)

    # MI Guessing (busca por localização)
    search_division: int = 20             # divisões por eixo na grade de busca
    search_min_features: int = 1          # mínimo de features para aceitar tile de busca
O uso de frozen=True garante que a configuração não pode ser modificada acidentalmente durante o pipeline. Para usar parâmetros diferentes, instancie um novo objeto: GeoreferencingConfig(min_features=12, ransac_reproj_thresh_px=3.0).

Pipeline Principal — 13 Etapas

A função georeference_image() em core/georeferencing.py orquestra todas as etapas, usando o ProcessLogger para cronometrar cada fase. Abaixo está a sequência completa com métricas geradas em cada etapa.

  1. 1
    Renderização da Imagem de Referência
    render_reference_image_to_size(layer, polygon_geom, width=2000) — renderiza a camada QGIS selecionada na extensão do polígono desenhado, em 2000 px de largura. Salva um GeoTIFF de debug temporário. timer: render_ref
  2. 2
    Carregamento da Imagem de Entrada
    cv2.imread(image_path, cv2.IMREAD_COLOR) — carrega o fotograma histórico digitalizado em BGR. timer: load_input
  3. 3
    Conversão para Escala de Cinza
    cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) para as duas imagens. Descritores de imagem trabalham em escala de cinza para independência de canais de cor.
  4. 4
    Detecção e Descrição de Keypoints
    detector.detect_and_compute() — aplica RootSIFT (ou outro detector via Strategy). Gera keypoints e descritores para as duas imagens. kp_src kp_ref timer: detect_src + detect_ref
  5. 5
    Correspondência de Features (Matching)
    matcher.match(desc1, desc2, kp1, kp2) — FLANNMatcher com KNN k=2 e Lowe's Ratio Test 0.75. Retorna good_matches e raw_matches. matches_raw matches_good timer: match
  6. 6
    Estimação de Homografia via RANSAC
    RansacHomographyEstimator.estimate(pares) — converte good_matches em pares de coordenadas e estima a matriz H 3×3. Retorna ResultadoHomografia com H, máscara de inliers e contagens. inliers timer: ransac
  7. 7
    Avaliação de Qualidade
    HomographyQualityEvaluator.is_acceptable(n_inliers, n_total) — duplo critério: inliers ≥ 8 E ratio ≥ 25%. Se não aceito, lança exceção com mensagem diagnóstica. inlier_ratio
  8. 8
    Cálculo do Erro de Reprojeção
    reprojection_stats(H, pares, mascara) — calcula RMS, mediana e P95 do erro em pixels para os inliers. Métricas de qualidade geométrica da transformação. reproj_rms reproj_median reproj_p95
  9. 9
    Warp Perspectivo
    aplicar_warp_perspective(img_src, H, size_ref, interpolation=INTER_CUBIC) — projeta a imagem de entrada no espaço da referência. Resultado tem o mesmo tamanho e perspectiva da referência renderizada. timer: warp
  10. 10
    Corte de Bordas Pretas
    cortar_bordas_pretas(warped) — detecta pixels não-zero e encontra o bounding box do conteúdo real, eliminando bordas introduzidas pelo warp. Retorna imagem e coordenadas do crop. timer: crop
  11. 11
    Cálculo da Extensão Geográfica
    calcular_extensao_geo(bounds_ref, warped_shape, crop_coords) — transforma as coordenadas do crop de pixels para coordenadas geográficas usando a resolução da referência. Retorna ExtensaoGeo com xmin, ymax, xres, yres e EPSG. timer: geo_calc
  12. 12
    Reamostragem e Salvar GeoTIFF
    salvar_geotiff_com_overviews(img, extensao, output_path, cfg) — reamostrar para ~1 m/pixel (INTER_CUBIC), salva com rasterio, aplica compressão JPEG quality 85 e constrói overviews 2×/4×/8×/16× para uso eficiente em SIG. timer: save
  13. 13
    Persistência do Log de Processo
    p_log.write_to_file(log_dir) — escreve o log estruturado K=V com todos os timers e métricas em arquivo JSON na pasta de debug. Remove GeoTIFF temporário da referência.

Detectores de Keypoints — Padrão Strategy

O dev-alvarez introduz um ABC BaseDetector que define a interface de todos os detectores. O DetectorManager implementa um mecanismo de fallback chain: tenta RootSIFT primeiro, e se falhar (ex.: poucos keypoints), tenta AKAZE, depois ORB.

class BaseDetector(ABC):
    @abstractmethod
    def detect_and_compute(self, image_gray: np.ndarray) -> Tuple[List, Optional[np.ndarray]]:
        ...

    @property
    @abstractmethod
    def descriptor_type(self) -> np.dtype:
        ...

RootSIFTDetector

Detector principal. Aplica normalização RootSIFT sobre os descritores SIFT de 128 dimensões:

sift = cv2.SIFT_create()
kps, desc = sift.detectAndCompute(gray, None)
# Normalização L1
desc /= (desc.sum(axis=1, keepdims=True) + 1e-7)
# Distância de Hellinger via raiz quadrada
desc = np.sqrt(desc)
Por que RootSIFT? O SIFT padrão usa distância Euclidiana (L2) entre descritores. A normalização L1 + raiz quadrada converte isso para a distância de Hellinger, provada superior para dados de histograma (como os descritores SIFT). Isso é especialmente importante para imagens históricas digitalizadas de filme, que têm características diferentes de imagens digitais modernas.

AKAZEDetector

Alternativo mais robusto em regiões com texturas complexas (ex.: áreas urbanas densas). Usa descritores binários (M-LDB) e é invariante a transformações não-lineares suaves. Threshold configurável: 0.001 (quanto menor, mais keypoints detectados).

ORBDetector

Alternativo mais rápido, baseado em FAST + BRIEF. Útil como último recurso em imagens com poucos features. Detecta até n_features=5000 por padrão.

DetectorManager — Fallback Chain

class DetectorManager:
    def __init__(self, detectors=[RootSIFTDetector(), AKAZEDetector(), ORBDetector()]):
        self.detectors = detectors

    def detect_and_compute(self, image_gray):
        for detector in self.detectors:
            kps, desc = detector.detect_and_compute(image_gray)
            if desc is not None and len(kps) >= MIN_THRESHOLD:
                return kps, desc
        return [], None

Matchers — Correspondência de Descritores

FLANNMatcher (principal)

Usa o algoritmo KD-Tree (FLANN) com trees=5 e checks=50 para encontrar os 2 vizinhos mais próximos de cada descritor. O Lowe's Ratio Test filtra correspondências ambíguas:

index_params = dict(algorithm=1, trees=5)      # FLANN_INDEX_KDTREE
search_params = dict(checks=50)
matcher = cv2.FlannBasedMatcher(index_params, search_params)
matches = matcher.knnMatch(desc1, desc2, k=2)

# Lowe's Ratio Test
good_matches = [
    m for m, n in matches
    if m.distance < 0.75 * n.distance  # match inequivocamente melhor que o 2º
]
Lowe's Ratio Test: Se o melhor match é muito próximo do segundo melhor, o ponto é ambíguo e descartado. O threshold 0.75 (de David Lowe, 2004) é o balanço comprovado entre precisão e recall. Para imagens históricas com muito ruído de filme, pode ser necessário diminuir para 0.70.

BFMatcher (alternativo)

Brute-Force Matcher com cross-check habilitado. Mais lento que FLANN para grandes conjuntos, mas garante que cada match é mutuamente o melhor vizinho (sem ratio test necessário). Útil quando FLANN falha em espaços de alta dimensão.

Estimação de Homografia — RANSAC

O RansacHomographyEstimator recebe uma lista de ParCorrespondencia (pares de coordenadas 2D) e estima a homografia 3×3 mais robusta possível.

@dataclass
class Ponto2D:
    x: float
    y: float

@dataclass
class ParCorrespondencia:
    origem: Ponto2D      # coordenada na imagem de entrada
    referencia: Ponto2D  # coordenada na imagem de referência

@dataclass
class ResultadoHomografia:
    H: Optional[np.ndarray]    # matriz 3×3
    mascara_inliers: Optional[np.ndarray]  # 1=inlier, 0=outlier
    n_corresp: int             # total de pares passados
    n_inliers: int             # pares dentro do limiar RANSAC

class RansacHomographyEstimator:
    def __init__(self, reproj_threshold_px=5.0, confidence=0.995):
        self.reproj_threshold_px = reproj_threshold_px
        self.confidence = confidence

    def estimate(self, pares: List[ParCorrespondencia]) -> ResultadoHomografia:
        pts_src = np.float32([(p.origem.x, p.origem.y) for p in pares])
        pts_ref = np.float32([(p.referencia.x, p.referencia.y) for p in pares])

        H, mask = cv2.findHomography(
            pts_src, pts_ref,
            cv2.RANSAC,
            self.reproj_threshold_px,
            confidence=self.confidence
        )
        n_inliers = int(mask.ravel().sum()) if mask is not None else 0
        return ResultadoHomografia(H=H, mascara_inliers=mask,
                                   n_corresp=len(pares), n_inliers=n_inliers)
Como funciona o RANSAC: Seleciona aleatoriamente 4 pares de pontos (mínimo para homografia), estima H, conta inliers (pontos dentro de 5.0 px da projeção), repete até confiança de 99.5%. Retorna a H com mais inliers encontrada.

Avaliador de Qualidade — HomographyQualityEvaluator

@dataclass(frozen=True)
class RegrasQualidadeHomografia:
    min_inliers: int = 4         # mínimo absoluto de inliers
    min_inlier_ratio: float = 0.2  # mínimo de 20% dos matches

class HomographyQualityEvaluator:
    def is_acceptable(self, n_inliers: int, n_total: int) -> bool:
        if n_total <= 0:
            return False
        ratio = n_inliers / float(n_total)
        return (n_inliers >= self.regras.min_inliers) and (ratio >= self.regras.min_inlier_ratio)

    def build_fail_message(self, n_inliers, n_total) -> str:
        ratio = (n_inliers / float(n_total)) if n_total > 0 else 0.0
        return (f"Qualidade insuficiente: inliers={n_inliers}/{n_total} "
                f"(razão={ratio:.2f}), mínimo esperado: "
                f"inliers>={self.regras.min_inliers} e razão>={self.regras.min_inlier_ratio:.2f}.")

O critério duplo é importante: poucos inliers absolutos podem indicar imagem com pouca textura; baixo ratio pode indicar muitos falsos positivos no matching. Ambas as condições devem ser satisfeitas para prosseguir.

Erro de Reprojeção — reprojection_stats

Módulo em utils/reprojection_stats.py. Após estimar a homografia, calcula o erro de reprojeção de cada inlier: a diferença em pixels entre onde o ponto original é projetado pela homografia e onde o match o colocou na referência.

def reprojection_stats(
    H: np.ndarray,
    pares: List[ParCorrespondencia],
    mask: np.ndarray
) -> Dict[str, float]:
    """
    Retorna: {
        'rms': float,     # raiz do erro quadrático médio (px)
        'median': float,  # mediana do erro (px)
        'p95': float      # percentil 95 do erro (px)
    }
    """
    inlier_pairs = [p for p, m in zip(pares, mask.ravel()) if m]
    pts_src = np.float32([(p.origem.x, p.origem.y) for p in inlier_pairs])
    pts_ref = np.float32([(p.referencia.x, p.referencia.y) for p in inlier_pairs])

    pts_proj = cv2.perspectiveTransform(pts_src.reshape(-1,1,2), H).reshape(-1,2)
    errors = np.linalg.norm(pts_proj - pts_ref, axis=1)

    return {
        'rms': float(np.sqrt(np.mean(errors**2))),
        'median': float(np.median(errors)),
        'p95': float(np.percentile(errors, 95))
    }
Interpretação prática: Para imagens históricas em ~1 m/pixel, um RMS de 2–3 px equivale a precisão de 2–3 metros. Resultados com RMS < 5 px são geralmente aceitáveis para análise histórica; < 2 px para uso cartográfico.

Warp Perspectivo

Módulo core/image_processing/warp.py. Aplica a homografia estimada para projetar a imagem de entrada no espaço de coordenadas da referência.

def aplicar_warp_perspective(
    img_src: np.ndarray,        # imagem de entrada (BGR)
    H: np.ndarray,              # homografia 3×3
    output_size: Tuple[int,int],  # (w, h) da referência renderizada
    interpolation: int = cv2.INTER_CUBIC
) -> np.ndarray:
    return cv2.warpPerspective(img_src, H, output_size,
                                flags=interpolation,
                                borderMode=cv2.BORDER_CONSTANT,
                                borderValue=0)

A interpolação INTER_CUBIC (bicúbica) é usada por padrão, pois produz resultados mais suaves que bilinear, sem os artefatos de ringing do Lanczos em bordas de baixo contraste.

Extração de Extensão Geográfica

Módulo core/image_processing/geo.py. Converte as coordenadas do crop (em pixels) para coordenadas geográficas, usando a resolução da imagem de referência renderizada.

@dataclass
class ExtensaoGeo:
    xmin: float    # longitude/E mínima do crop
    ymax: float    # latitude/N máxima do crop
    xres: float    # resolução X (unidades CRS / pixel)
    yres: float    # resolução Y (unidades CRS / pixel, negativo para raster norte-acima)
    epsg: str      # código EPSG herdado da camada de referência

def calcular_extensao_geo(
    bounds: QgsRectangle,   # bounding box da referência em coordenadas geográficas
    shape_warped: Tuple,    # (h, w) da imagem após warp (tamanho da referência)
    y_min: int, x_min: int  # canto superior-esquerdo do crop em pixels
) -> ExtensaoGeo:
    xres = bounds.width()  / shape_warped[1]
    yres = bounds.height() / shape_warped[0]
    nova_xmin = bounds.xMinimum() + x_min * xres
    nova_ymax = bounds.yMaximum() - y_min * yres
    return ExtensaoGeo(xmin=nova_xmin, ymax=nova_ymax,
                       xres=xres, yres=-yres, epsg=...)

Salvar GeoTIFF com Overviews

Módulo core/image_processing/save_geotiff.py. Reamostrar a imagem para a resolução alvo, salvar com metadados geoespaciais completos e construir overviews para visualização eficiente em SIG.

@dataclass
class ReamostragemConfig:
    target_resolution: float = 1.0      # metros/pixel
    interpolation: int = cv2.INTER_CUBIC
    clamp_upsampling: bool = False       # evita ampliar imagem além do original
    overview_levels: List[int] = (2, 4, 8, 16)
    jpeg_quality: int = 85

def salvar_geotiff_com_overviews(
    img_bgr: np.ndarray,
    extensao: ExtensaoGeo,
    output_path: str,
    cfg: ReamostragemConfig
) -> None:
    # 1. Calcular nova dimensão
    geo_width  = abs(extensao.xres * img_bgr.shape[1])
    geo_height = abs(extensao.yres * img_bgr.shape[0])
    new_w = max(1, round(geo_width  / cfg.target_resolution))
    new_h = max(1, round(geo_height / cfg.target_resolution))

    # 2. Reamostrar
    img_resampled = cv2.resize(img_bgr, (new_w, new_h), interpolation=cfg.interpolation)
    img_rgb = cv2.cvtColor(img_resampled, cv2.COLOR_BGR2RGB)

    # 3. Escrever GeoTIFF com rasterio
    new_xres = geo_width  / new_w
    new_yres = geo_height / new_h
    transform = rasterio.transform.from_origin(extensao.xmin, extensao.ymax,
                                                new_xres, new_yres)
    with rasterio.open(output_path, 'w',
                       driver='GTiff', crs=f'EPSG:{extensao.epsg}',
                       transform=transform, dtype='uint8',
                       width=new_w, height=new_h, count=3,
                       compress='jpeg', jpeg_quality=cfg.jpeg_quality,
                       photometric='ycbcr', nodata=0) as dst:
        dst.write(img_rgb.transpose(2,0,1))
        dst.build_overviews(list(cfg.overview_levels), Resampling.average)
        dst.update_tags(ns='rio_overview', resampling='average')
Overviews (pirâmides): Níveis 2×/4×/8×/16× reduzem o tempo de renderização no QGIS de minutos para segundos ao visualizar a imagem em escalas menores. São construídos internamente no arquivo GeoTIFF (COG — Cloud Optimized GeoTIFF compatível).

ProcessLogger — Log Estruturado com Timers

Módulo utils/process_logger.py. Registra cada fase do pipeline com duração em segundos e métricas K=V, e escreve o resultado como JSON atômico (write temp + rename) para evitar arquivos corrompidos.

class ProcessLogger:
    def start(self, phase: str) -> None:
        """Inicia o timer da fase."""
        self._timers[phase] = time.perf_counter()

    def end(self, phase: str) -> float:
        """Para o timer e registra a duração em segundos."""
        elapsed = time.perf_counter() - self._timers[phase]
        self._durations[phase] = elapsed
        return elapsed

    def log(self, key: str, value) -> None:
        """Registra um par K=V (métrica, parâmetro, etc.)."""
        self._data[key] = value

    def write_to_file(self, output_dir: str, filename: str = "process_log.json") -> None:
        """Escreve JSON atômico: cria temp → rename."""
        payload = {
            'durations_s': self._durations,
            'metrics': self._data,
            'timestamp': datetime.now().isoformat()
        }
        tmp = os.path.join(output_dir, filename + '.tmp')
        dst = os.path.join(output_dir, filename)
        with open(tmp, 'w', encoding='utf-8') as f:
            json.dump(payload, f, indent=2, ensure_ascii=False)
        os.replace(tmp, dst)  # operação atômica no sistema de arquivos

_fazer_mosaico() — Criação do Canvas

Calcula o canvas mínimo que abrange ambas as imagens após a projeção, aplica o warp na img2 e mescla img1 sobre o resultado (pixels > 10 em qualquer canal prevalecem).

MI Guessing — Busca por Localização Desconhecida

Módulo core/miguessing.py. Quando a localização geográfica aproximada de uma imagem histórica é desconhecida, o sistema divide o polígono de busca em uma grade e tenta georreferenciar a imagem em cada célula, identificando a melhor correspondência.

divideWithMetricSuperposition()

Divide um bounding box em uma grade N×N com sobreposição métrica configurável entre células adjacentes:

def divideWithMetricSuperposition(
    bbox: QgsRectangle,
    superposition: Tuple[float, float],   # sobreposição (sX, sY) em unidades CRS
    config: GeoreferencingConfig = GeoreferencingConfig()
) -> List[QgsRectangle]:
    """
    Gera config.search_division² células.
    Cada célula sobrepõe sX unidades com a vizinha à direita
    e sY unidades com a vizinha abaixo.
    """
    divs = config.search_division  # padrão: 20 → 400 células
    dX = (sX * (divs - 1) + bbox.xMaximum() - bbox.xMinimum()) / divs
    dY = (sY * (divs - 1) + bbox.yMaximum() - bbox.yMinimum()) / divs
    pX = [bbox.xMinimum() + (dX - sX) * n for n in range(divs)]
    pY = [bbox.yMinimum() + (dY - sY) * n for n in range(divs)]
    return [QgsRectangle(pX[i], pY[j], pX[i]+dX, pY[j]+dY)
            for i in range(divs) for j in range(divs)]

descImg() e descRef() — Pré-computação de Descritores

Para eficiência, os descritores da imagem de entrada são calculados uma vez (descImg()) e reutilizados para cada célula da grade. A referência é renderizada e descrita separadamente para cada célula (descRef()).

check() — Avaliação de uma Célula

Executa matching + RANSAC + avaliação de qualidade para um par (imagem, célula de referência). Retorna (aceito, resultado, pares, stats, inliers).

zoom_to_spatial_res()

Converte nível de zoom de mapa (1–20) para resolução espacial em metros/pixel no sistema de coordenadas Web Mercator (EPSG:3857):

def zoom_to_spatial_res(zoom: int) -> float:
    return 156416.0 / pow(2, zoom)
# zoom 14 → ~9.55 m/px  |  zoom 17 → ~1.19 m/px  |  zoom 19 → ~0.30 m/px

Renderização da Camada de Referência

Módulo core/render/render_reference.py. Converte a camada QGIS (raster ou vetor) na extensão do polígono para um array NumPy, simulando o que o usuário vê no canvas do QGIS.

render_reference_image_to_size()

def render_reference_image_to_size(
    layer,
    polygon_geom: QgsGeometry,
    width: int = 2000,
    debug_output_dir: str = None
) -> Tuple[Optional[np.ndarray], Optional[QgsRectangle], Optional[str], Optional[str]]:
    """
    Retorna: (array BGR, bounds, epsg_code, path_geotiff_temp)
    """
    bounds = polygon_geom.boundingBox()
    height = int((bounds.height() / bounds.width()) * width)

    settings = QgsMapSettings()
    settings.setLayers([layer])
    settings.setExtent(bounds)
    settings.setDestinationCrs(layer.crs())
    settings.setOutputSize(QSize(width, height))

    image = QImage(QSize(width, height), QImage.Format_ARGB32)
    painter = QPainter(image)
    job = QgsMapRendererCustomPainterJob(settings, painter)
    job.start()
    job.waitForFinished()
    painter.end()

    # Converte QImage → NumPy BGR
    ptr = image.constBits()
    arr = np.frombuffer(ptr, dtype=np.uint8).reshape((height, width, 4))
    bgr = arr[:, :, :3][:, :, ::-1]  # BGRA → BGR
    return bgr, bounds, str(layer.crs().authid()).split(':')[1], path_temp
